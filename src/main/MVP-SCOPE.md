# 🌸 Flowers Application - MVP Scope

## 👤 Tizimdagi Rollar (Roles)
* Customer (Mijoz): Gullarni ko'radi, savatga qo'shadi va buyurtma beradi.
* Florist (Sotuvchi): Gullarni tizimga qo'shadi va kelgan buyurtmalarni qabul qiladi.
* Admin (Boshqaruvchi): Foydalanuvchilarni va umumiy tizimni nazorat qiladi.
